PROJECT BACKGROUND — WHY THE CODE EXISTS
The manuscript studies planner-filter-consistent time–energy-optimal motion for a redundant manipulator. Stage 1 plans a free-duration, collision/constraint-aware trajectory with modeled non-regenerative electrical energy and time in the objective. Stage 2 tracks the planned trajectory under a momentum disturbance observer and Slotine–Li nominal control, then projects the nominal torque through a robust HOCBF-QP. Time-dependent tracking and uncertainty envelopes tighten the Stage-1 constraints so that a sufficiently well-certified nominal trajectory need not activate the filter. The proposed Section IV will eventually assess (A) nominal filter consistency, (B) dynamic versus candidate-wise constant envelopes, and (C) an unreserved planner under the same filter. Today we are building only the closed-loop execution components needed to approach A2; we are NOT implementing or claiming those final comparisons.

B. Implement the momentum-based disturbance observer exactly
   Plant dynamics: M(q) qddot + C(q,qdot) qdot + g(q) + F(qdot) = tau_applied + d(t).
   Momentum p=M(q) qdot; estimate dhat=z+K_o p.
   For the manuscript's Christoffel-consistent C with Mdot=C+C^T, use
       zdot = -K_o [dhat + tau_applied + C(q,qdot)^T qdot - g(q) - F(qdot)].
   The continuous ideal observer satisfies d(dhat)/dt = K_o(d-dhat); derived disturbance error is dtilde=d-dhat and dtilde_dot=dot d-K_o*dtilde.
   Initialization: dhat(t0)=0, z(t0)=-K_o*M(q0)*qdot0; initial envelope varpi_i0=dbar_i. If a moving start is allowed, do NOT assume z0=0. Keep true d(t) private to the plant. Preserve the observer and global clock on replanning; do not reset varpi to zero.
   At every control update, use the torque actually applied after filtering/recovery, not u_nom. Make the discrete observer-update method and its timing explicit; compare its behavior against an independent continuous-time reference during unit tests. Do not infer continuous-time envelopes from a discrete implementation without accounting for numerical/delay error.

C. Implement Slotine–Li nominal tracking with exact error sign convention
   e=q_p-q; edot=qdot_p-qdot; s=edot+Lambda*e;
   qdot_r=qdot_p+Lambda*e; qddot_r=qddot_p+Lambda*edot;
   u_nom=M(q)*qddot_r+C(q,qdot)*qdot_r+g(q)+F(qdot)+kappa*M(q)*s-dhat.
   delta_tau=tau_applied-u_nom. Verify algebraic dimensions, torque sign, initial zero tracking error when reference is initialized from measured state, and residual/tracking identities against the manuscript. Do not silently introduce alternate controller forms or switch to SMC/ST-SMC.

D. Implement robust HOCBF-QP, respecting relative degree and units
   Define joint position barriers h_{i,+}=qmax_i-q_i and h_{i,-}=q_i-qmin_i; speed barriers h_{v,i,+}=qdotmax_i-qdot_i and h_{v,i,-}=qdotmax_i+qdot_i; manipulability h_man=det(J_v(q) J_v(q)^T)-w_min^2, with J_v the *3x7 translational flange Jacobian*.
   For each position-level h_j(q), use the HOCBF form
       H_j(q,qdot,a)=grad(h_j)^T*a + qdot^T*Hess(h_j)*qdot
                       +(alpha_1+alpha_2)*grad(h_j)^T*qdot + alpha_1*alpha_2*h_j.
   Predicted acceleration for a candidate command tau:
       a_hat(tau)=solve(M, tau+dhat-[C(q,qdot)*qdot+g+F]).
   Robust rows:
       Psi_j(tau)=H_j(q,qdot,a_hat(tau))
                  - sum_l |[grad(h_j)^T M^-1]_l| varpi_l(t) >= 0;
       Xi_{i,+}(tau)=-a_hat_i(tau)+alpha_v*h_{v,i,+}
                     -sum_l |[M^-1]_{il}| varpi_l(t) >= 0;
       Xi_{i,-}(tau)=+a_hat_i(tau)+alpha_v*h_{v,i,-}
                     -sum_l |[M^-1]_{il}| varpi_l(t) >= 0.
   Minimize 0.5*||tau-u_nom||_2^2 subject to all robust rows and -tau_max <= tau <= tau_max. Build affine inequality matrices deterministically with positive row normalization from T29. Avoid explicit matrix inversion where numerical solves are available. Use the exact signed inequalities and log every raw and normalized slack, QP status, residual and applied torque. If the selected library's API or convention disagrees, record the discrepancy and resolve transparently.
   The safe-set entry checks must include h_j>=0, psi_{1,j}=dot h_j+alpha_1*h_j>=0, speed and torque limits. Do not confuse slack > numerical tolerance with formal invariance. Never quietly drop the manipulability barrier to obtain feasibility.
   Implement the manuscript recovery branch (soft QP / bounded braking) as a separate clearly flagged module ONLY if its required gains/weights and explicit semantics are available; otherwise leave it disabled with a safe fail-closed protective-stop request. Never treat the recovery branch as part of the certified nominal theorem.
